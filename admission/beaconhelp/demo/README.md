# 🎬 Demo Video - BeaconHelp

## Descripción del Guión

Este directorio contiene el guión completo para la demo en video de BeaconHelp, presentada por el equipo TriDevs para el reto de Senasoft. La presentación está estructurada en 5 secciones principales con participantes específicos.

## 👥 Equipo TriDevs

- **Estefanía Ríos**: Especialista UX/UI
- **Catherine Arias Ramos**: Experta en Seguridad
- **Cristofer Scalante**: Desarrollador Principal

## 📋 Estructura del Guión

### 1. Introducción (Estefanía)
**Duración**: 30-45 segundos
- Presentación del equipo TriDevs
- Definición del problema: violencia intrafamiliar/género y emergencias
- Introducción de la solución: app confidencial con múltiples funcionalidades

### 2. Prompts Utilizados (Catherine)
**Duración**: 20-30 segundos
- Explicación del uso de IA en el desarrollo
- Mención de 15+ prompts en v0.dev
- Proceso de prototipado visual a código

### 3. Construcción Colaborativa (Cristofer)
**Duración**: 25-35 segundos
- Stack tecnológico: React + Vite
- Metodología colaborativa con GitHub
- Uso de Trae IA para desarrollo

### 4. Demo Funcionando (Todos)
**Duración**: 60-90 segundos
- Demostración en vivo del prototipo
- Funcionalidades clave: botón de pánico, geolocalización
- Navegación por la aplicación

### 5. Cierre (Todos)
**Duración**: 15-20 segundos
- Reflexión sobre IA y trabajo colaborativo
- Mensaje final del impacto de la tecnología

## 🎯 Objetivos de la Demo

- Mostrar la funcionalidad completa de BeaconHelp
- Demostrar el uso efectivo de IA en el desarrollo
- Destacar la metodología colaborativa del equipo
- Presentar una solución real a problemas sociales

## 📱 Funcionalidades a Demostrar

1. **Botón de Pánico**: Activación rápida en emergencias
2. **Geolocalización**: Compartir ubicación automáticamente
3. **Contactos de Emergencia**: Gestión y llamadas rápidas
4. **Recursos de Apoyo**: Líneas de ayuda especializadas
5. **Chat con IA**: Asistente inteligente para emergencias
6. **Navegación Intuitiva**: Diseño mobile-first

## 🎥 Notas de Producción

### Configuración Técnica
- **Plataforma**: Zoom/Teams para grabación
- **Resolución**: 1080p mínimo
- **Audio**: Micrófono individual para cada participante
- **Pantalla**: Compartir pantalla para demo en vivo

### Tips para la Presentación
- Mantener energía y entusiasmo
- Transiciones fluidas entre participantes
- Demo en dispositivo móvil real si es posible
- Backup con grabación de pantalla
- Ensayar timing de cada sección

- Logo de TriDevs

- Profesionalismo: Presentación pulida y coordinada
