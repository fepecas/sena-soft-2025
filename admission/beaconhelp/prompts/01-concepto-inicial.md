# 🚀 Prompt Inicial - Concepto de BeaconHelp

## Prompt Original

```
Necesito crear una aplicación web de botón de pánico para emergencias en Colombia. 
La aplicación debe:
- Ser desarrollada en React con Vite
- Tener un botón de pánico prominente y fácil de usar
- Permitir gestión de contactos de emergencia
- Incluir recursos de apoyo (líneas de ayuda, centros de atención)
- Tener un diseño moderno y accesible
- Funcionar bien en dispositivos móviles
- Incluir geolocalización para emergencias

El nombre de la aplicación es "BeaconHelp" y debe transmitir confianza y seguridad.
```

## Contexto del Prompt

### Problema Identificado
- Necesidad de una herramienta digital para situaciones de emergencia
- Falta de acceso rápido a contactos de emergencia
- Dificultad para compartir ubicación en situaciones críticas
- Necesidad de recursos de apoyo centralizados

### Objetivos del Proyecto
1. **Accesibilidad**: Fácil de usar en situaciones de estrés
2. **Rapidez**: Activación inmediata del botón de pánico
3. **Confiabilidad**: Funcionamiento estable en emergencias
4. **Completitud**: Solución integral para diferentes tipos de emergencias

## Decisiones de Diseño Resultantes

### Tecnológicas
- **React + Vite**: Desarrollo rápido y performance optimizada
- **Bootstrap**: Framework CSS para diseño consistente
- **React Router**: Navegación fluida entre páginas
- **Lucide React**: Iconografía clara y reconocible

### UX/UI
- **Botón de pánico central**: Elemento más prominente de la interfaz
- **Colores de emergencia**: Rojo para pánico, verde para seguridad
- **Tipografía clara**: Legibilidad en situaciones de estrés
- **Navegación simple**: Máximo 2 clics para cualquier función

### Funcionales
- **Geolocalización automática**: Sin intervención manual del usuario
- **Contactos rápidos**: Acceso directo a llamadas y mensajes
- **Recursos categorizados**: Organización por tipo de emergencia
- **Modo offline**: Funcionalidades básicas sin conexión

## Refinamientos del Prompt

### Iteración 1: Especificación Técnica
```
Para BeaconHelp, necesito definir la arquitectura técnica:
- Estructura de carpetas escalable
- Sistema de estado global con Context API
- Componentes reutilizables
- Integración con APIs de geolocalización
- Manejo de errores robusto
```

### Iteración 2: Experiencia de Usuario
```
Mejorar la UX de BeaconHelp:
- Animaciones suaves pero no distractoras
- Feedback inmediato para todas las acciones
- Accesibilidad para usuarios con discapacidades
- Soporte para diferentes tamaños de pantalla
```

### Iteración 3: Funcionalidades Avanzadas
```
Agregar características avanzadas:
- Chat con IA para asistencia inmediata
- Integración con WhatsApp para compartir ubicación
- Sistema de alertas personalizables
- Modo de emergencia con interfaz simplificada
```
