# 🚨 BeaconHelp - Sistema de Emergencia Personal

BeaconHelp es una aplicación de emergencia personal diseñada para brindar asistencia inmediata en situaciones de riesgo, especialmente enfocada en la prevención de violencia de género y seguridad ciudadana en Colombia.

Este repositorio concentra la documentación, diseño, prompts, prototipos y la demo del MVP. Es un punto único de referencia para entender cómo nació la idea, cómo se estructuró y qué se logró en esta primera etapa.

## 📂 Estructura del Repositorio

- **contexto/** → Documentación estratégica: descripción del producto, propuesta de valor, funciones clave y user journey.
- **diseño/** → Wireframes, mockups y guía de estilo visual.
- **prompts/** → Colección de prompts utilizados en cada fase (UX, diseño, prototipo).
- **prototipo/** → Documentación del código fuente del MVP en React + Vite.
- **demo/** → Guión y video de demostración.

## 🚀 Cómo navegar

1. **Inicia en `contexto/`** para conocer el producto y su valor.
2. **Explora `diseño/`** para ver cómo se visualizó y validó la experiencia.
3. **Revisa `prompts/`** y observa cómo la IA fue parte del proceso.
4. **En `prototipo/`** encontrarás el código del MVP listo para ejecutar.
5. **Finalmente, en `demo/`** accede al guión y al video demostrativo.

## 🎯 Funcionalidades Principales

- **Botón de Pánico**: Activación inmediata de alertas de emergencia
- **Contactos de Emergencia**: Gestión y notificación automática
- **Recursos de Apoyo**: Acceso rápido a líneas de ayuda especializadas
- **Asistente IA**: Chat inteligente para orientación y apoyo
- **Geolocalización**: Envío automático de ubicación en emergencias
- **Educación**: Contenido preventivo sobre seguridad personal
- **Reportes**: Sistema de denuncia y seguimiento
