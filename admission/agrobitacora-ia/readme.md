¡Excelente jugada! 🙌 Si quieres darle tu idea a una *IA que genera interfaces* (como Uizard, Galileo AI, o hasta MidJourney con UI prompts), lo ideal es un *prompt detallado* que explique exactamente: flujo, usuario final, contexto y restricciones.

## 📝 Prompt para generar interfaces de AgroBitácora IA

> Diseña la interfaz móvil de una aplicación llamada *AgroBitácora IA*, un asistente conversacional para agricultores familiares.
>
> ### 🎯 Objetivo principal:
>
> Ayudar a *productores individuales en zonas rurales* a registrar actividades agrícolas, recibir alertas del clima, y consultar recomendaciones, todo de manera *simple, inclusiva y visual*.
>
> ### 👤 Perfil del usuario:
>
> * Campesinos con poca alfabetización digital.
> * Algunos no saben leer → necesitan interacción *por voz* y respuestas en *audio*.
> * Dispositivos de gama baja (Android básicos).
> * Conectividad limitada → *modo offline* necesario.
>
> ### 🧭 Flujo principal:
>
> 1. *Pantalla de inicio / Login*
>
>    * Registro sencillo: nombre, cultivo principal, tamaño aproximado de la parcela.
>    * Opción de registro *por voz* (ejemplo: “Me llamo Pedro y siembro maíz en media hectárea”).
> 2. *Menú principal* (íconos grandes y claros, accesibles en WhatsApp-like o app ligera):
>
>    * 📝 Registrar actividad
>    * 🔔 Consultar alertas
>    * 📖 Ver bitácora
>    * ❓ Preguntar a la IA
> 3. *Registrar actividad*
>
>    * Entrada de voz o texto.
>    * Ejemplo: el usuario dice “Hoy aboné la tierra”.
>    * La IA guarda automáticamente la actividad con fecha/hora.
> 4. *Consultar alertas*
>
>    * Muestra recordatorios de clima y etapas del cultivo.
>    * Ejemplo: “Lloverá mañana, evita regar hoy”.
>    * Opción de escuchar la alerta en *audio*.
> 5. *Bitácora digital*
>
>    * Vista cronológica de las actividades registradas.
>    * Debe ser visual y simple (línea de tiempo con íconos de siembra, riego, cosecha).
>    * Opción de exportar PDF o compartir con un técnico rural.
> 6. *Preguntar a la IA*
>
>    * Espacio libre de chat: el agricultor puede preguntar dudas comunes (ejemplo: “¿Cómo controlar plagas en fríjol?”).
>    * La IA responde en texto y audio.
>
> ### 🎨 Estilo visual:
>
> * Íconos grandes, coloridos y fáciles de identificar (ejemplo: gota para riego, semilla para siembra).
> * Interfaz limpia, accesible para personas con poca lectura.
> * Botones de voz visibles y fáciles de usar.
> * Colores cálidos y relacionados con el campo (verde, marrón, azul cielo).
>
> ### ⚙ Funcionalidades técnicas clave:
>
> * *Modo offline:* guardar datos localmente y sincronizar cuando haya señal.
> * *Soporte de audio:* tanto entrada como salida de voz.
> * *Ligera y rápida*, apta para celulares de gama baja.
>
> Genera *pantallas para cada etapa del flujo*: login, menú principal, registro de actividad, consulta de alertas, bitácora, chat con IA.
