# 📌 PrediktIA

**PrediktIA** es un proyecto de inteligencia artificial diseñado para **anticipar necesidades del usuario y ofrecer recomendaciones proactivas**, facilitando decisiones rápidas y mejorando la experiencia digital.

Este repositorio concentra la documentación, diseño, prompts, prototipos y la demo del MVP. Es un punto único de referencia para entender cómo nació la idea, cómo se estructuró y qué se logró en esta primera etapa.

---

## 📂 Estructura del Repositorio

- **contexto/** → Documentación estratégica: descripción del producto, propuesta de valor, funciones clave y user journey.
- **diseño/** → Wireframes, mockups y guía de estilo visual.
- **prompts/** → Colección de prompts utilizados en cada fase (UX, diseño, prototipo).
- **prototipo/** → Código fuente del MVP en React + Tailwind.
- **demo/** → Guion y video de demostración.

---

## 🚀 Cómo navegar

1. Inicia en `contexto/` para conocer el producto y su valor.
2. Explora `diseño/` para ver cómo se visualizó y validó la experiencia.
3. Revisa `prompts/` y observa cómo la IA fue parte del proceso.
4. En `prototipo/` encontrarás el código del MVP listo para ejecutar.
5. Finalmente, en `demo/` accede al guion y al video demostrativo.
