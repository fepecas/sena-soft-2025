# 🚦 InfoMultas  

**InfoMultas** es un proyecto de inteligencia artificial diseñado para **consultar y gestionar fotomultas en Colombia**, ofreciendo a los conductores información confiable, orientación vial y un mapa interactivo de cámaras de tránsito.  

Este repositorio concentra la documentación, diseño, prompts, prototipo y la demo del MVP. Es un punto único de referencia para entender cómo nació la idea, cómo se estructuró y qué se logró en esta primera etapa.  

---

## 📂 Estructura del Repositorio  

- **contexto/** → Documentación estratégica: descripción del problema, propuesta de valor, funcionalidades principales y flujo de usuario.  
- **diseño/** → Wireframes generados con **Stitch**, mockups, prototipo visual y guía de estilo.  
- **prompts/** → Colección de prompts utilizados en cada fase (ideación, UX, diseño, prototipo).  
- **prototipo/** → Código fuente del MVP en **React + Tailwind**, con integración de mapa y chatbot.  
- **demo/** → Guion narrado y video de demostración.  

---

## 🚀 Cómo navegar  

1. Inicia en `contexto/` para conocer el producto y el valor que entrega a los usuarios.  
2. Explora `diseño/` para ver la evolución desde wireframes hasta el prototipo visual.  
3. Revisa `prompts/` y descubre cómo utilizamos IA para acelerar el desarrollo.  
4. En `prototipo/` encontrarás el código del MVP listo para explorar.  
5. Finalmente, en `demo/` accede al guion y al video demostrativo.
