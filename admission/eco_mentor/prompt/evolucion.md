# Prompt Base 1

Necesito un mockup interactivo para EcoMentor, un tutor financiero IA. Debe incluir: pantalla de bienvenida, chat para recopilar datos financieros, plan financiero personalizado, simuladores de inversión (acciones, CDT, fondos, tarjetas de crédito) con decisiones y consecuencias, y un informe final con consejos. Diseño moderno, fácil de usar, para jóvenes y adultos. Que simule interacción básica del usuario

# Prompt Base 2

Crea un mockup interactivo para EcoMentor, tutor financiero IA con 5 pantallas: bienvenida, chat para recopilar datos financieros paso a paso, plan financiero personalizado, simuladores interactivos (acciones, CDT, fondos, tarjetas), e informe final con recomendaciones. Incluye análisis por perfil de riesgo, edad e ingresos, plan de acción claro y diseño moderno, responsivo, optimizado para jóvenes y adultos. Simula interacciones realistas.
