# HELIOS – Carpeta `knowledge/`
Esta carpeta contiene conocimiento base que HELIOS consultará **antes** de buscar en internet. 
Actualízala con frecuencia y verifica fechas/vigencias.

## Estructura
- `guias_senasoft/` – Resúmenes, criterios y FAQ del evento.
- `plantillas/` – Archivos para ejecutar rápido (pitch, plan de trabajo, checklist).
- `recursos_financiamiento/` – Fondos, convocatorias y enlaces oficiales.
- `ejemplos_prompts/` – Prompts listos para otras IAs (Leonardo, Magnus, Quiliano, ChatGPT).
- `casos_reales/` – Lecciones de proyectos/competencias previas (anónimos o públicos).

## Sugerencias de uso
1. HELIOS prioriza estos archivos; si falta algo, complementa con navegación web.
2. Mantén fuentes oficiales y fechas vigentes.
3. Para cada documento, agrega *"Última actualización: YYYY-MM-DD"* arriba.
