# HELIOS – Asistente de IA para SENASoft 2025

## 🌟 Descripción General
HELIOS es un asistente inteligente diseñado para potenciar el rendimiento de los equipos en SENASoft, combinando creatividad, estrategia y herramientas prácticas para destacar frente a la competencia.
Este proyecto integra 7 funciones clave, alineadas con el reglamento, los criterios de evaluación y las necesidades reales de los participantes.

**🚀 Funcionalidades**

Asesoría sobre SENASoft
Explica reglas, criterios, estrategias y buenas prácticas para destacar.

Creación de pitch ganador
Diseña presentaciones claras, persuasivas y basadas en datos.

Networking efectivo
Planifica conexiones estratégicas, mensajes y preguntas para interactuar con jurados, organizadores y otros equipos.

Búsqueda de recursos y financiamiento
Localiza convocatorias, becas, fondos y eventos con requisitos, fechas y pasos concretos.

Optimización del trabajo en equipo
Aplica metodologías ágiles, asigna tareas, controla tiempos y hace seguimiento del progreso.

Evaluación de ideas y prototipos
Analiza viabilidad, impacto, diferenciación y propone mejoras.

Detección de ventajas competitivas únicas
Identifica elementos diferenciales que aseguren relevancia y valor real.

**🛠️ Instalación y configuración**

Clona o descarga el repositorio.

Abre el proyecto en Visual Studio Code.

Configura el system prompt en tu entorno IA con las instrucciones de HELIOS.

Asegúrate de cargar la carpeta knowledge como base de conocimiento.

**💡 Uso**

Selecciona la funcionalidad que necesites (del 1 al 7).

Proporciona datos específicos para obtener respuestas precisas.

HELIOS te guiará con pasos claros, plantillas y ejemplos.

Aplica las recomendaciones y ajusta según resultados.

**📋 Recomendaciones para la competencia**

Usa funciones combinadas para maximizar el impacto.

Enfócate en valor real y no solo en ideas llamativas.

Demuestra viabilidad y aplicabilidad más allá del evento.

Documenta todo para respaldar tus decisiones.

**🏆 Objetivo final**

Que HELIOS deje una huella memorable en jurados, organizadores y competidores, posicionando tu proyecto entre los 3 primeros lugares de SENASoft a nivel nacional.
