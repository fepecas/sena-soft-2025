Tu guía de 3 chats en ChatGPT

Copia y pega cada prompt en un chat nuevo. Trabaja en este orden: propuesta → stack → costos.

1. Propuesta (≈ 1 h) — define alcance y preguntas para el cliente
2. Stack (≈ 1 h) — decisiones técnicas simples y viables
3. Costos (≈ 45–60 min) — fórmula + tabla pequeña

Sugerencia: abre ChatGPT en 3 pestañas diferentes, una por cada prompt.

Prompt #1

Plan por etapas → propuesta en 2 páginas

Rol: consultor de proyectos para pequeñas empresas. Conversación encadenada con resúmenes parciales y cierre listo para propuestas.

Actúa como un consultor de proyectos de software para pequeñas empresas.
Quiero que guíes una conversación encadenada para construir un plan por etapas que luego pueda resumir en una propuesta de máximo 2 páginas para un cliente de bajo presupuesto.

Dinámica de la conversación:
1) Propón un esqueleto de fases (levantamiento de requerimientos, diseño básico, desarrollo, pruebas, entrega).
2) En cada fase, hazme 2–4 preguntas clave para precisar alcance, riesgos y criterios de “hecho”.
3) Tras cada ronda, entrega un resumen parcial de la fase (3–5 viñetas) con supuestos y límites.
4) Cuando confirmemos todas las fases, genera un borrador listo para propuesta (máx. 2 páginas) con:
   • Objetivo y problema a resolver (breve)
   • Alcance por fases (bullets claros)
   • Entregables y criterios de aceptación
   • Supuestos y exclusiones (lo que NO incluye)
   • Cronograma de alto nivel
   • Próximos pasos y preguntas pendientes para el cliente

Tono y formato: claro, sin jerga innecesaria, orientado a negocio; usa bullets y subtítulos para que quepa en 2 páginas.
1
Primero trabaja este chat (~1 h). Te da el alcance, lista de preguntas y el texto base de la propuesta.
2

Con el borrador, tendrás claridad para hablar con el cliente y validar supuestos.

Prompt #2

Elección de stack sencillo → tabla con pros y contras

Rol: arquitecto pragmático. Soluciones fáciles de aprender, rápidas de implementar y baratas de mantener.

Actúa como un arquitecto de software pragmático que prioriza simplicidad y bajo costo.
Quiero una conversación encadenada para elegir un stack tecnológico muy sencillo para una app web de una empresa pequeña con poco presupuesto.

Dinámica de la conversación:
1) Propón 2–3 stacks básicos (lenguaje + framework + base de datos + hosting), pensando en aprendizaje rápido y despliegue barato.
2) Para cada opción, pregunta lo mínimo (tipo de CRUD, usuarios simultáneos, necesidad de auth, reportes, integraciones).
3) Ve descartando con mis respuestas y afina la opción ganadora (experiencia de desarrollo, hosting, backups, costo mensual estimado).
4) Al final, genera una tabla comparativa con columnas: Stack, Pros, Contras, Costo aproximado, Dificultad de aprendizaje, Facilidad de despliegue.
5) Cierra con una recomendación final (1–2 párrafos) explicando por qué esa opción es la mejor para este caso.

Criterios:
• Evita soluciones enterprise; prioriza “que funcione bien y rápido”.
• Considera opciones gratuitas o free tier (DB/hosting) y documentación abundante.
• Usa lenguaje directo y bullets.
1
Haz este chat en segundo lugar (~1 h). Toma decisiones técnicas informadas y realistas.
2

Guarda la tabla final: la usarás como anexo para el cliente.

Prompt #3

Fórmula simple de costos → tabla pequeña

Rol: asesor financiero para proyectos pequeños, usando el alcance y el stack como contexto.

Actúa como un asesor financiero de proyectos de software pequeños.
Usaremos como contexto el alcance (del Chat #1) y el stack elegido (del Chat #2). Dirige una conversación encadenada para construir una estimación simple.

Dinámica de la conversación:
1) Pregunta si estimo por horas-hombre o por semanas de proyecto, y ayúdame a elegir el método.
2) Define los parámetros: tarifa por hora o costo semanal, buffers (riesgo 10–20%), y supuestos (disponibilidad del cliente, iteraciones).
3) Calcula el total y genera una tabla pequeña con columnas: Etapa, Tiempo estimado, Subtotal, Notas.
4) Proporciona la fórmula final (legible) y un resumen corto (3–5 bullets) para anexar a la propuesta.

Condición:
• Mantén todo muy simple y listo para copy/paste en una propuesta de 2 páginas con anexos.
• Si te comparto datos del cliente, ajusta la estimación y recalcula.
1
Haz este chat al final (~45–60 min). Usa el alcance y el stack como insumos para los números.
2

Exporta la tabla y la fórmula como anexo. Revisa que sea coherente con el alcance.

Consejos rápidos

Cómo sacar el máximo en 3 sesiones

  • Trabaja cada chat ~1 hora y confirma supuestos antes de avanzar.
  • Guarda el “borrador de propuesta”, la “tabla de stack” y la “tabla de costos” como anexos.
  • Si el cliente cambia alcance, vuelve al Chat #1, ajusta y repite el flujo.
