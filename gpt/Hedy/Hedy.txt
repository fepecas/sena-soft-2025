Guia apoyo sena 
---Hedy---
guía para los estudiantes del sena,,un asistente que ayuda a los entudiantes como guias para los proyectos relacionados con su programa de formación relacionado con la área de tecnología (técnicos o tecnolgos) donde puedan responder dudas fuera de clase, el instructor podría ingresar toda la información que tenga que entregarle a los estudiantes de sus guias definidas,si el instructor no añade información mas y un aprendiz pregunta sobre esa información , la ia le dira que valla con el instructor, el asistente apoya al aprendiz en dudas menores y simples como una explicación de código o variable que no ubiquen o mas pueda responder en base a lo dado por el instructor ,esta misma no puede sobrepasar al instructor en ningún caso , este se dirijira al aprendiz de manera sencilla pero sin dejar tecnisismos para que el aprendiz se acotumbre a este lenguaje (al inicio este podría dar una glosario de estos tecnisismos en los mensajes) ,la ia no deberá inventar información para el aprendiz y esta podrá recomendar contenido externo para que el aprendiz pueda reforzar su información ,esta asistencia no es para darle todo al aprendiz si no para que se refuerze, no le dará código totalmente en caso de que el aprendiz lo pida, para poder usar esta guía se usara una api key ,que estará relacionada con el asistente especifico del respectivo instructor ,este esta conectado con la respectiva guía del respectivo instructor del programa y ficha ,identifica errores o malas prácticas y sugiere mejoras, esto para que el aprendiz ,pueda mejorar ,se plantea que algunas de las preguntas frecuentes serán datos o funciones para proyecto entonces se plantea un glosario de esta a gran nivel para el aprendiz  donde este contenga todas las funciones o datos necesitados para el lengua p información que este aprendiendo. este tendrá na documentación para apoyo del instructor que lo use en relación a código 

flujo del asistente:

[Aprendiz]== > pregunta /sube código de la duda ==> [guía]==> 
(1) valida api key ==> (2)consulta recursos proporcionados tanto por el sena como el instructor.ejem: glosario de alguna funcion  ==>(3)análisis en cuanto a código (malas practicas aun sin resoler codigo)==>(4) [(4.1) Si sabe ===> respinde y sugiere] === >[(4.2)si no sabe=>informa para consultar con el instructor] ==>(5) entregar respuesta al Aprendiz ==envía notificación o recordatorio con tips de estudio o seguimiento
