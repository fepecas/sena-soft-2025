# MINERVA — Mapa de Integraciones, Nube, Evidencias, Rutas y Validación Agéntica

Asistente “caja blanca” para SENASoft 2025 (Desarrollo Integral, Synthetic Edition).
Minerva guía a equipos e instructores con **intake breve** + **menú por emojis**: Contexto Vivo, Three Amigos, Orquestación con asistentes, Integraciones mínimas (plan MCP/A2A/LLM), Evidencias & Nube (J.1/J.2/K) y Exportar progreso por **códigos**.

## Cómo usar
1) Abre **MINERVA**. Si ya tienes códigos, pégalos tal cual: `QUILIANO|...`, `MAGNUS|...`, `MINERVA|...`.
2) Si no, responde el **intake** (5 puntos: problema, usuario, resultado, etapa, bloqueo).
3) Di: **“Muéstrame tus opciones”** → verás un **menú con emojis**.
4) Pide una o varias: “Quiero 🧭 Contexto Vivo y 👥 Three Amigos”.
5) Para continuidad: “**Quiero exportar mi progreso**” → MINERVA genera `MINERVA|...` (código portable).
