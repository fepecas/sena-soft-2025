# Team Roles

## Roles Principales

### Frontend Developer
**Hace:** Interfaces, componentes, páginas web
**Necesita:** HTML, CSS, JavaScript, React/Vue
**Tareas:** 
- Crear pantallas y formularios
- Conectar con APIs
- Hacer diseño responsive

### Backend Developer  
**Hace:** APIs, base de datos, lógica del servidor
**Necesita:** Node.js/Python/Java, SQL, APIs REST
**Tareas:**
- Crear endpoints
- Manejar base de datos
- Autenticación y seguridad

### Full-Stack Developer
**Hace:** Frontend + Backend
**Necesita:** Todo lo anterior
**Tareas:** Features completas de inicio a fin

### DevOps
**Hace:** Deploy, servidores, CI/CD
**Necesita:** Docker, AWS/GCP, GitHub Actions
**Tareas:** 
- Configurar deploy automático
- Manejar servidores
- Monitoreo

## Equipos Recomendados

**MVP (3-4 personas):**
- 1-2 Full-Stack 
- 1 Frontend
- 1 Backend/DevOps

**Producto Mediano (6-8 personas):**
- 2 Frontend
- 2 Backend  
- 1 DevOps
- 1 QA
- 1 Tech Lead

**Proyecto Grande (10+ personas):**
- Múltiples equipos pequeños
- Especialistas (Security, Data)
- Arquitectos
- Product Managers
