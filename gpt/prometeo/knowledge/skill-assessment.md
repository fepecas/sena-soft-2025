## Niveles Básicos

**Junior (1-2):** Necesita supervisión, tareas simples
**Mid (3-4):** Trabaja independiente, resuelve problemas
**Senior (5):** Experto, mentoreo, decisiones técnicas

## Evaluación Rápida

**Preguntas Técnicas:**
- Explica [concepto clave de su rol]
- ¿Cómo resolverías [problema típico]?
- Revisa este código y mejóralo

**Proyecto Mini:**
- 2-3 horas de coding
- Problema real del dominio
- Evaluar calidad y approach

## Identificar Gaps

1. **Mapear skills necesarios** vs skills actuales
2. **Priorizar gaps críticos** para el proyecto
3. **Crear plan de training** individual
4. **Asignar mentores** para areas débiles

## Red Flags

- No puede explicar sus decisiones
- Código sin tests
- No acepta feedback
- No trabaja en equipo
