# Estimation

## Story Points (Simple)

**1 punto = 2 horas:** Cambio pequeño (fix bug, cambio texto)
**2 puntos = 4 horas:** Feature simple conocida  
**3 puntos = 1 día:** Feature mediana
**5 puntos = 2 días:** Feature compleja
**8 puntos = 3 días:** Muy complejo, considerar dividir

## Cómo Estimar

1. **Leer la tarea** - Entender qué hay que hacer
2. **Pensar complejidad** - ¿Es fácil o difícil?
3. **Considerar unknowns** - ¿Qué no sabemos?
4. **Agregar testing** - Siempre sumar tiempo de pruebas
5. **Votar en equipo** - Consenso del equipo

## Template Rápido

```
Tarea: Login de usuarios

Frontend: Formulario + validación = 3 pts
Backend: API + JWT + DB = 5 pts  
Testing: Unit + integration = 2 pts
Total: 10 pts = ~1 semana para 1 persona
```

## Velocity del Equipo

**Medir después de 2-3 sprints:**
- Sprint 1: 20 puntos completados
- Sprint 2: 25 puntos completados
- Sprint 3: 22 puntos completados
- **Promedio: 22 pts por sprint**

## Errores Comunes

- No incluir tiempo de testing
- No pensar en bugs/debugging
- Ser demasiado optimista
- No dividir tareas grandes
- No considerar code review
