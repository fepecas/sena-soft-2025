# Languages

## Frontend

### JavaScript
**Cuándo:** Siempre necesario para web
**Pros:** Universal, fácil de empezar, flexible
**Contras:** Tipos dinámicos pueden causar bugs

### TypeScript  
**Cuándo:** Proyectos medianos/grandes, equipos múltiples
**Pros:** Menos bugs, mejor IDE, refactoring seguro
**Contras:** Setup inicial, curva de aprendizaje

## Backend

### JavaScript/Node.js
**Cuándo:** Full-stack JS, MVPs rápidos, I/O intensivo
**Pros:** Mismo lenguaje que frontend, async nativo
**Contras:** Single thread, CPU intensivo problemático
**Aprende si:** Ya sabes JS frontend

### Python
**Cuándo:** Data science, AI/ML, scripting, desarrollo rápido  
**Pros:** Fácil de leer, productivo, muchas librerías
**Contras:** Lento, GIL para concurrencia
**Aprende si:** Eres principiante o haces data/AI

### Java
**Cuándo:** Enterprise, sistemas grandes, equipos grandes
**Pros:** Robusto, performance, ecosistema maduro
**Contras:** Verbose, lento para prototipar
**Aprende si:** Vas a trabajar en corporaciones

### Go
**Cuándo:** Microservicios, APIs high-performance, concurrencia
**Pros:** Simple, rápido, buen para servidores
**Contras:** Ecosistema limitado, a veces muy simple
**Aprende si:** Quieres hacer backend moderno

### Rust
**Cuándo:** Performance extremo, systems programming
**Pros:** Ultra rápido, memory safe
**Contras:** Curva de aprendizaje muy empinada
**Aprende si:** Performance es crítico

### PHP
**Cuándo:** WordPress, legacy systems, hosting barato
**Pros:** Fácil deploy, hosting económico
**Contras:** Inconsistente, performance moderado
**Aprende si:** Haces sitios web tradicionales

## Móvil

### Swift (iOS)
**Cuándo:** Apps iOS nativas, performance crítico
**Pros:** Rápido, APIs completas de iOS
**Contras:** Solo iOS

### Kotlin (Android)  
**Cuándo:** Apps Android nativas
**Pros:** Mejor que Java, interop con Java
**Contras:** Solo Android

### Dart (Flutter)
**Cuándo:** Cross-platform con una sola codebase
**Pros:** Un código para iOS/Android
**Contras:** Ecosistema más pequeño

## Recomendaciones por Experiencia

### Principiante Total:
1. **JavaScript** - Fundamental para web
2. **Python** - Fácil de aprender, versátil

### Ya sabes JavaScript:
1. **TypeScript** - Mejor JS
2. **Node.js** - Backend con JS

### Ya tienes base:
1. **Go** - Backend moderno
2. **React Native** - Móvil con JS

### Desarrollador Avanzado:
1. **Rust** - Performance extremo
2. **Kotlin** - Android moderno
