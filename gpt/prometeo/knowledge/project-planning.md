# Project Planning

## Metodologías

**Scrum - Para proyectos con cambios:**
- Sprints de 2 semanas
- Daily standups (15 min)
- Sprint planning + retrospectiva
- Equipos 3-7 personas

**Kanban - Para flujo continuo:**
- To Do → In Progress → Done
- Límite de 3 tasks por persona
- Ideal para mantenimiento

## Fases Básicas

1. **Definir que construir** - MVP + features principales
2. **Elegir tecnologías** - Stack técnico adecuado al equipo
3. **Dividir trabajo** - Epic → Stories → Tasks
4. **Estimar tiempo** - Story points o días
5. **Asignar tareas** - Por rol y capacidad

## Herramientas

- **Linear/Jira** - Gestión de tareas
- **Figma** - Diseños y wireframes
- **GitHub Projects** - Si usas GitHub
- **Notion** - Documentación

## Template Sprint Planning

1. **Objetivo del sprint** - Una frase clara
2. **Capacidad del equipo** - Días disponibles
3. **Tareas prioritarias** - Del backlog
4. **Riesgos** - Que puede bloquearnos
