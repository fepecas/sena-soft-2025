# Learning Paths

## Frontend Developer (6-12 meses)

### Mes 1-2: Fundamentos
**HTML & CSS:**
- Semántica HTML
- CSS Grid y Flexbox
- Responsive design
- **Proyecto:** Landing page responsive

**JavaScript Básico:**
- Variables, funciones, arrays
- DOM manipulation
- Events
- **Proyecto:** Todo app vanilla JS

### Mes 3-4: JavaScript Avanzado
- Async/await, Promises
- Modules ES6+
- Local storage
- Fetch API
- **Proyecto:** Weather app con API

### Mes 5-6: React
- Components y Props
- State y useEffect
- React Router
- **Proyecto:** Dashboard con múltiples páginas

### Mes 7-12: Especialización
- TypeScript
- Testing (Jest)
- Performance optimization
- **Proyecto:** E-commerce completo

## Backend Developer (6-12 meses)

### Mes 1-2: Fundamentos
**Lenguaje Base (Node.js/Python):**
- Sintaxis básica
- Functions y modules
- Package managers
- **Proyecto:** Calculator CLI

### Mes 3-4: Server & APIs
- HTTP basics
- REST APIs
- Express/FastAPI
- **Proyecto:** CRUD API

### Mes 5-6: Database
- SQL básico
- PostgreSQL/MongoDB
- ORMs (Prisma/SQLAlchemy)
- **Proyecto:** API con base de datos

### Mes 7-12: Producción
- Authentication (JWT)
- Deploy (Railway/Heroku)
- Testing
- **Proyecto:** API completa en producción

## Full-Stack Developer (12-18 meses)

### Primeros 6 meses: Frontend
Seguir path de Frontend Developer

### Meses 7-12: Backend
- Node.js + Express
- PostgreSQL
- Authentication
- Deploy

### Meses 13-18: Integración
- Frontend + Backend integration
- Advanced state management
- Performance optimization
- **Proyecto:** App full-stack completa

## DevOps Engineer (12+ meses)

### Meses 1-3: Fundamentos
- Linux command line
- Git avanzado
- Docker básico
- **Proyecto:** Containerizar una app

### Meses 4-6: Cloud
- AWS/GCP basics
- CI/CD con GitHub Actions
- **Proyecto:** Deploy automático

### Meses 7-12: Avanzado
- Kubernetes
- Infrastructure as Code
- Monitoring
- **Proyecto:** Infraestructura completa

## Schedule Semanal Sugerido

### Principiante (10-15h/semana)
- **2-3h diarias** entre semana
- **4-6h** fin de semana
- **1h** práctica diaria mínimo

### Con trabajo (5-10h/semana)
- **1h** antes del trabajo
- **2-3h** después del trabajo (3 días)
- **4h** fin de semana

### Intensivo (30+h/semana)
- **6-8h** diarias
- Proyectos grandes
- Contribuir open source

## Milestones Importantes

### 3 meses: Primer proyecto
- Deploy algo funcional
- Mostrar en portfolio
- Aplicar a primer trabajo junior

### 6 meses: Proyecto complejo  
- Full-stack app
- Múltiples features
- Buenas prácticas

### 12 meses: Primer trabajo
- Portfolio sólido
- 3-5 proyectos
- Networking activo

## Tips de Aprendizaje

1. **Aprende haciendo** - Más proyectos, menos tutoriales
2. **Documenta tu progreso** - Blog, GitHub
3. **Join communities** - Discord, Twitter, local meetups
4. **Teach others** - Best way to solidify learning
5. **Stay consistent** - Better daily 1h than weekend 10h
