# Recursos adicionales para Lyra

Este archivo centraliza enlaces y materiales de apoyo para mejorar la precisión y consistencia de Lyra. Úsalo como referencia del equipo (no normativa) y manténlo actualizado.

- Glosario QA: <https://greensqa.com/glosario/#m>
- Guía de microcopy y tono editorial: <https://uxmag.com/articles/the-essential-guide-to-microcopy-and-becoming-a-more-literate-designer>
