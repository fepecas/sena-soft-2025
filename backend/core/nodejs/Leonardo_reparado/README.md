# Leonardo está incompleto

## Visión General

El proyecto "Leonardo está incompleto" es una iniciativa destinada a mejorar el sistema de gestión de métricas de inscripción para el programa SENASoft. Este proyecto busca proporcionar nuevas métricas que permitan una mejor comprensión del desempeño de los aprendices y facilitar la toma de decisiones informadas.

## Propósito

El propósito de este proyecto es desarrollar una API que permita consultar métricas específicas relacionadas con las inscripciones y el rendimiento de los aprendices. A través de esta API, los usuarios podrán acceder a información relevante y actualizada, lo que contribuirá a optimizar el proceso educativo.

## Contexto

En el contexto actual, es fundamental contar con herramientas que permitan analizar y evaluar el progreso de los aprendices. La falta de métricas adecuadas puede llevar a decisiones erróneas y a una gestión ineficiente de los recursos. Este proyecto se propone abordar esta necesidad mediante la implementación de un sistema robusto y flexible.

## Objetivos del Reto

1. **Desarrollar una API**: Crear una API RESTful que permita a los usuarios consultar métricas de inscripción y rendimiento.
2. **Implementar nuevas métricas**: Definir y calcular métricas que sean relevantes para el seguimiento del progreso de los aprendices.
3. **Facilitar el acceso a la información**: Proporcionar una interfaz sencilla y clara para que los usuarios puedan interactuar con el sistema y obtener la información que necesitan.
4. **Documentar el proyecto**: Crear una documentación completa que explique cómo instalar, utilizar y contribuir al proyecto.

Este README proporciona una visión general del proyecto y su importancia en el contexto educativo. Para más detalles sobre la instalación, uso y contribuciones, consulte los archivos de documentación en la carpeta `docs`.
