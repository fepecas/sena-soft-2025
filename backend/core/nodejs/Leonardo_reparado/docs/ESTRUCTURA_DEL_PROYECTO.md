# ESTRUCTURA DEL PROYECTO

El proyecto "Leonardo está incompleto" está organizado de manera que facilita su comprensión y mantenimiento. A continuación, se describe la estructura de carpetas y archivos del proyecto, así como el propósito de cada uno.

## Raíz del Proyecto

- **README.md**: Este archivo proporciona una visión general del proyecto, incluyendo su propósito, contexto y los objetivos del reto.

## Carpeta `docs`

Esta carpeta contiene la documentación del proyecto, organizada en varios archivos:

- **INTRODUCCION.md**: Ofrece una introducción al proyecto, explicando el contexto y la necesidad de nuevas métricas para el sistema Leonardo.

- **FUNCIONALIDAD.md**: Detalla las funcionalidades del sistema, incluyendo cómo Leonardo puede consumir métricas de inscripción y responder a preguntas específicas sobre los aprendices.

- **INSTALACION.md**: Describe los pasos necesarios para instalar y configurar el proyecto en un entorno local, incluyendo dependencias y configuraciones requeridas.

- **USO.md**: Explica cómo utilizar el sistema, incluyendo ejemplos de comandos y cómo interactuar con la API.

- **API.md**: Documenta los endpoints disponibles en la API, incluyendo descripciones de las rutas, parámetros requeridos y ejemplos de respuestas.

- **ESTRUCTURA_DEL_PROYECTO.md**: Este archivo, que estás leyendo, describe la estructura del proyecto y el propósito de cada archivo y carpeta.

- **SEMILLAS_DE_DATOS.md**: Proporciona información sobre las semillas de datos que se pueden cargar en la base de datos para pruebas, incluyendo ejemplos de datos y su formato.

- **CONTRIBUIR.md**: Detalla cómo los desarrolladores pueden contribuir al proyecto, incluyendo pautas para enviar pull requests y cómo reportar problemas.

## Carpeta `ejemplos`

Esta carpeta contiene ejemplos prácticos para facilitar la interacción con la API:

- **RUTAS_EJEMPLO.md**: Contiene ejemplos de rutas que se pueden utilizar para interactuar con la API, mostrando cómo hacer solicitudes y qué respuestas esperar.

- **CONSULTAS_DE_PRUEBA.md**: Proporciona ejemplos de consultas que se pueden realizar en la API, incluyendo los parámetros necesarios y ejemplos de respuestas esperadas.

## Conclusión

La estructura del proyecto está diseñada para ser clara y accesible, permitiendo a los desarrolladores y usuarios entender rápidamente cómo navegar y utilizar el sistema "Leonardo está incompleto".
