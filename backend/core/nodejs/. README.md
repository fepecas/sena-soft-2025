Descripción del Proyecto
Este proyecto es una aplicación web de pila completa (Full-Stack) diseñada para gestionar y visualizar datos de aprendices. El backend se construyó con Node.js, Express y MongoDB (usando Mongoose), actuando como una API RESTful que permite realizar operaciones CRUD y análisis de datos. El frontend se desarrolló con Vue.js para ofrecer una interfaz de usuario dinámica y moderna que consume los datos de la API.

El objetivo principal de esta aplicación es:

Registrar la información de los aprendices.

Analizar datos clave, como la cantidad de aprendices por centro de formación, instructores recomendados, y más.

Proveer una interfaz intuitiva para la gestión de estos registros.

-------
El backend es el servidor que expone los endpoints de la API.

Requisitos
Node.js (versión 18 o superior)

MongoDB (instancia local o en la nube, como MongoDB Atlas)

Pasos
Clona el repositorio o navega a la carpeta de tu proyecto.

Instala las dependencias: En la terminal, dentro de la carpeta del backend, ejecuta:

'npm install'
Configura tu base de datos: Asegúrate de que tu cadena de conexión a MongoDB esté configurada en tu archivo de entorno (.env si lo usas) o directamente en el archivo server.js.

Inicia el servidor: Ejecuta el siguiente comando para arrancar el servidor:

'node server.js'
Si usas nodemon para reinicios automáticos, usa nodemon server.js.

Verifica los endpoints: El servidor estará corriendo en http://localhost:3000. Puedes usar Postman o tu navegador para probar los endpoints GET, como:

http://localhost:3000/api/aprendices-por-centro

http://localhost:3000/api/aprendices-por-departamento
.------------
El frontend es la interfaz de usuario que interactúa con el backend.

Requisitos
Node.js (versión 18 o superior)

Vista CLI

Pasos
Navega a la carpeta del frontend: En tu terminal, ve a la carpeta de tu proyecto de Vue.js.

Instala las dependencias: Ejecuta el siguiente comando:
'npm install'

inicia el servidor de desarrollo:
'npm run serve'
Accede a la aplicación: El frontend estará disponible en tu navegador en http://localhost:8080 (o el puerto que se muestre en tu terminal).

Backend
server.js: Archivo principal del servidor que configura Express, la conexión a la base de datos y las rutas.

models/aprendiz.js: El modelo de Mongoose que define la estructura de los documentos de aprendices.

controllers/controller_routeruser.js: Contiene todas las funciones de lógica de negocio (controladores) que manejan las peticiones de los endpoints.

Interfaz
src/App.vue: El componente principal de Vue que contiene toda la lógica para consumir la API y renderizar la interfaz de usuario.

src/main.js: Archivo de entrada de Vue.
